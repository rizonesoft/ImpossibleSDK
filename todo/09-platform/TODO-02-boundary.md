# TODO-02 -- The Windows Boundary

> **Goal:** A shipping program built with the SDK can reach Windows only through the SDK's Windows layer, and the build proves it: no Windows name on the link line outside that layer, no Windows header outside it, no system handle or pointer in an exported header, and the tier the program needs is measured once.

> **Current state:** Measured 2026-11-27 at `8d5bf9a`. `cmake/ImpossibleSDK.cmake` links every program with `kernel32 user32 gdi32 shell32 winmm ws2_32 bcrypt crypt32 dwmapi`, so any object can call `CreateFileW`. `tools/check_imports.py` reads the finished executable and refuses an import outside the tier, and it refuses any machine but x64. `include/impossible/window.h` declares `void *native` (the live `HWND`) and `void *cursor` (an `HCURSOR`) in `im_window`, which `samples/window/main.c`, `tests/fixtures/reopen.c`, `tests/fixtures/test_host.c`, `tests/fixtures/test_dirty.c`, `docs/guide/first-window.md` and `docs/guide/drawing.md` build or read. `abi/tiers.json` has `functions` only, and `src/window.c` looks up `DwmSetWindowAttribute` with `GetProcAddress` unlisted. `tests/fixtures/forbidden.c` is built with `UNCHECKED` so the import check can reject it.
