# Security

Please do not open a public issue for a security problem. Use **Security, Report a vulnerability** on this repository's page: the report is private.

Say what happens, how to make it happen, and what it would allow. Reports about these count in particular:

- a program that passes the import check and still calls a function outside its tier;
- memory errors in the kit or in Impossible UI;
- a build that uses anything but the pinned tools or the pinned SDK;
- a file reader that a file can harm.

Only the newest `main` is supported; there is no release yet. A problem in the operating system belongs to [Impossible OS](https://github.com/rizonesoft/impossible-os/security).
