# The Impossible SDK identity

A kit: a case with a window of controls rising out of it. The window has Windows 11's round corners, and the case carries code brackets round the Impossible OS logo's square, centred on it. In the wordmark, SDK stands on an accent button of Windows 11's look. Chosen by the owner on 2026-11-23.

| File | Use |
| --- | --- |
| `icon/icon.svg` | 48 pixels and larger |
| `icon/icon-16.svg`, `-20`, `-24`, `-32` | Their own drawing, on whole pixels |
| `icon/glyph.svg` | One colour, in the text colour around it |
| `icon.ico`, `png/` | Windows and everything that takes a picture |
| `wordmark-dark.png`, `wordmark-light.png` | The name, on a dark and on a light ground |
| `banner-dark.png`, `banner-light.png` | The head of the README |
| `social-preview.png` | GitHub, Settings, Social preview |
| `badge-dark.png`, `badge-light.png` | Programs built with the SDK |

The rules are those of Impossible OS: a 48 grid, seen from the front, lit from above, no outlines, the logo's blues. The wordmark is set in Plus Jakarta Sans, the banner in Selawik and Cascadia Code (all OFL). `tools/brand.py` renders everything but the sources. The window in the banners is a preview of Impossible UI: today its button is built.
