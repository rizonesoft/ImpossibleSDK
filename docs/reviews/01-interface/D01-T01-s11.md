1. **P1. The 1/256 px guarantee fails on a 1920 px coordinate.** Path: rotate `(1920, 0)` by 30°. Evidence: ran `python3 -c 'import math; v=math.cos(math.radians(30)); print(abs(v-round(v*65536)/65536)*1920)'` and got `0.004662233877681388` px, above `0.00390625` px. This error occurs when storing the coefficient, before point multiplication. Keep higher precision for linear coefficients and composition, define the supported coordinate and chain ranges, and make this vector a mandatory oracle case. Also specify matrix convention, angle units, rounding, outward rectangle bounds, and checked failure when a result or inverse is unrepresentable.
