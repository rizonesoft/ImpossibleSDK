## Architecture and API

1. **Header (`parts/deflate/deflate.h`):**
   - Formats: `im_deflate_format`: `IM_DEFLATE_RAW = 0`, `IM_DEFLATE_ZLIB = 1`, `IM_DEFLATE_GZIP = 2`.
   - Efforts: `im_deflate_effort`: `IM_DEFLATE_FAST = 0` (zlib level 1 equivalent), `IM_DEFLATE_BALANCED = 1` (zlib level 6 equivalent), `IM_DEFLATE_BEST = 2` (zlib level 9 equivalent).
   - Named status codes (`im_deflate_status`): `IM_DEFLATE_OK = 0` (stream finished and trailer emitted), `IM_DEFLATE_NEED_INPUT = 1` (need more input or `is_eof=true`), `IM_DEFLATE_OUT_FULL = 2` (output buffer full, call again with more output space), `IM_DEFLATE_BAD_ARG = 3` (invalid pointer, format, effort, or state).
   - Caller-allocated fixed-size struct `im_deflate` (`sizeof(im_deflate) < 512 KiB`, well under the 1 MiB fixed memory limit, zero heap allocation):
     - `uint8_t window[65536]` (2 x 32 KiB sliding history + lookahead window).
     - `uint16_t head[32768]` and `uint16_t prev[32768]` (15-bit 3-byte hash chain tables, shifted by 32768 with saturating subtraction on slide).
     - `uint16_t dist_buf[32768]` and `uint8_t litlen_buf[32768]` (per-block LZ77 token buffer: `dist == 0` is literal `litlen_buf[i]`; `dist > 0` is match `(dist, litlen_buf[i] + 3)`).
     - Block flushing triggers strictly on deterministic raw-byte (`>= 32768` bytes spanned in `window[]` so `window[block_start .. strstart)` always holds the exact raw bytes for stored-block fallback) or token-count (`>= 32768` tokens) thresholds, or on `is_eof == true`. Never depends on caller `in_len` or `out_cap` chunk sizes, guaranteeing byte-for-byte identical output under arbitrary input/output cuts.
     - Streaming bit/block emitter state (`uint64_t bitbuf`, `uint32_t bitcnt`, `emit_phase`, `emit_idx`, active Huffman code/length tables, stored/fixed/dynamic header emission state) draining directly into caller `out[0..out_cap]` even when `out_cap == 1`.
     - Running `uint32_t check` (Adler-32 for zlib, CRC-32 for gzip via `parts/checksum`) and `uint64_t total_in` (for gzip `ISIZE = (uint32_t)(total_in & 0xFFFFFFFFu)`).
   - Public functions (every public symbol documented above its declaration for `tools/site/build.py`):
     - `im_deflate_status im_deflate_init(im_deflate *st, im_deflate_format fmt, im_deflate_effort effort);`
     - `im_deflate_status im_deflate_step(im_deflate *st, const uint8_t *in, size_t in_len, bool is_eof, size_t *in_used, uint8_t *out, size_t out_cap, size_t *out_used);`
     - `im_deflate_status im_deflate_all(im_deflate_format fmt, im_deflate_effort effort, const uint8_t *in, size_t in_len, uint8_t *out, size_t out_cap, size_t *out_len);`

2. **Compression Algorithm (`parts/deflate/deflate.c`):**
   - **Wrappers:**
     - `IM_DEFLATE_ZLIB`: deterministic RFC 1950 2-byte header (`CMF = 0x78` for 32 KiB window DEFLATE; `FLG` with `FLEVEL = 0/2/3` for Fast/Balanced/Best and `FCHECK` making `(CMF*256 + FLG) % 31 == 0`), followed by DEFLATE blocks, followed by 4-byte big-endian Adler-32.
     - `IM_DEFLATE_GZIP`: deterministic RFC 1952 10-byte header (`1F 8B 08 00 00 00 00 00 XFL FF`, `XFL = 4` for Fast, `0` for Balanced, `2` for Best, `OS = 255` unknown, zero MTIME), followed by DEFLATE blocks, followed by 4-byte little-endian CRC-32 and 4-byte little-endian `ISIZE`.
     - `IM_DEFLATE_RAW`: bare RFC 1951 DEFLATE stream (compatible with `zipfile` and `zlib.decompress(..., -15)`).
   - **LZ77 Match Finding:**
     - `IM_DEFLATE_FAST`: greedy matching (`max_chain = 4`, `good_len = 4`, `nice_len = 8`, `max_insert_len = 4`).
     - `IM_DEFLATE_BALANCED`: lazy matching (`max_lazy = 16`, `max_chain = 128`, `good_len = 8`, `nice_len = 128`, full hash updates).
     - `IM_DEFLATE_BEST`: deep lazy matching (`max_lazy = 258`, `max_chain = 4096`, `good_len = 32`, `nice_len = 258`, full hash updates).
     - Strict `MAX_DIST = 32768`, `MIN_MATCH = 3`, `MAX_MATCH = 258`, and `strstart - dist <= valid_history` invariant across slides so no match ever references uninitialized window bytes.
   - **Optimal Length-Limited Canonical Huffman + Block Selection:**
     - Package-Merge (pure integer, zero recursion, bounded fixed scratch) to build optimal length-limited canonical Huffman codes: max 15 bits for lit/len (286 symbols) and dist (30 symbols), max 7 bits for code-length alphabet (19 symbols).
     - Handles degenerate 0-symbol and 1-symbol trees cleanly (RFC 1951 compliant: always includes EOB 256 in lit/len; if 0 distance symbols used, emits a single 1-bit dummy distance symbol 0).
     - RLE encodes combined `HLIT + HDIST` code lengths with symbols 16/17/18 and trims trailing zero code-length codes in RFC 1951 order (`16, 17, 18, 0, 8, 7, 9, 6, 10, 5, 11, 4, 12, 3, 13, 2, 14, 1, 15`, `HCLEN >= 4`).
     - Computes exact bit cost of stored block (aligned to byte boundary), fixed Huffman block, and dynamic Huffman block, and emits whichever is strictly smallest.
   - **Freestanding / Portable Compliance:**
     - Zero `<stdlib.h>`/`<stdio.h>`/`<string.h>`/OS calls, zero floating point, compiles cleanly under `-ffreestanding -fno-builtin -mgeneral-regs-only -Werror` via `tools/check_parts.py`.
