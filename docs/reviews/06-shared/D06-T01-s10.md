## Architecture and API

1. **PNG Writer (`parts/png/png.h` + `parts/png/write.c`):**
   - `im_png_write_mode`: `IM_PNG_WRITE_AUTO = 0` (losslessly choose optimal color type among 0=Gray, 2=RGB, 3=Indexed+optional tRNS, 4=Gray+Alpha, 6=RGBA), `IM_PNG_WRITE_GRAY = 1`, `IM_PNG_WRITE_RGB = 2`, `IM_PNG_WRITE_INDEXED = 3`, `IM_PNG_WRITE_GRAY_ALPHA = 4`, `IM_PNG_WRITE_RGBA = 5`.
   - `im_png_write_options`: `im_png_write_mode mode`, `im_deflate_effort effort` (default `IM_DEFLATE_BALANCED` when `opts == NULL`).
   - `im_image_error im_png_encode(const im_image *img, const im_png_write_options *opts, const im_png_alloc *alloc, uint8_t **out_data, size_t *out_len);`
     - Validates all pointers, `width >= 1`, `height >= 1`, `width <= 0x7FFFFFFF`, `height <= 0x7FFFFFFF`, `stride >= width * 4`, `byte_size >= (size_t)stride * height` (overflow-checked), valid `img->format` (`IM_PIXEL_BGRA8` or `IM_PIXEL_RGBA8`), valid `mode` and `effort`.
     - Zeroes `*out_data = NULL; *out_len = 0;` on entry; on any error frees every allocation made via `alloc->free` with its exact allocated size.
     - Explicit modes verify lossless representability (e.g. `GRAY`/`GRAY_ALPHA` require `r == g == b`; `GRAY`/`RGB` require `a == 255`; `INDEXED` requires `<= 256` unique RGBA colors; otherwise returns `IM_IMAGE_INVALID`).
     - `IM_PNG_WRITE_AUTO` performs a single pass to classify `all_opaque`, `all_gray`, and unique RGBA colors (up to 256 via fixed hash table):
       - Sorts palette entries so translucent entries (`a < 255`) come first, trimming `tRNS` to the last non-255 entry (omitting `tRNS` when `all_opaque`).
       - Uses sub-byte packed bit depths (1, 2, 4, or 8 bit) for indexed images when `unique_count <= 2/4/16/256`, and selects between Gray (0), Gray+Alpha (4), Indexed (3), RGB (2), and RGBA (6) by smallest lossless raw+palette byte footprint.
     - Per-row adaptive filtering (for color types 0, 2, 4, 6): evaluates all 5 RFC 2083 filters (0=None, 1=Sub, 2=Up, 3=Average, 4=Paeth) in pure integer arithmetic and picks the row filter minimizing `sum(abs((int8_t)b))`. Indexed (type 3) uses filter 0 (None).
     - Streams filtered rows through `im_deflate_step(IM_DEFLATE_ZLIB, effort)` (with `im_deflate` allocated through `alloc->alloc` to keep stack frames tiny).
     - Emits ONLY required chunks: 8-byte PNG signature, `IHDR`, optional `PLTE`, optional `tRNS`, `IDAT` (CRC-32 via `im_crc32`), and `IEND`. Zero `tIME`, `tEXt`, `zTXt`, `iTXt`, `pHYs`, `sRGB`, `gAMA`, `cHRM`, or `iCCP` chunks.

2. **BMP Writer (`parts/bmp/bmp.h` + `parts/bmp/write.c`):**
   - `im_bmp_write_mode`: `IM_BMP_WRITE_AUTO = 0` (24-bpp `BI_RGB` when all pixels opaque, 32-bpp V4 `BI_BITFIELDS` when any pixel has `a < 255`), `IM_BMP_WRITE_24 = 1` (refuses translucent pixels with `IM_IMAGE_INVALID`), `IM_BMP_WRITE_32 = 2` (always 32-bpp V4 `BI_BITFIELDS` with explicit `R=0x00FF0000, G=0x0000FF00, B=0x000000FF, A=0xFF000000` masks and `bV4CSType = 0x73524742`).
   - `im_image_error im_bmp_encode(const im_image *img, im_bmp_write_mode mode, const im_bmp_alloc *alloc, uint8_t **out_data, size_t *out_len);`
     - Validates all inputs and overflow-checks total BMP file size `<= 0xFFFFFFFFu` (`IM_IMAGE_TOO_LARGE` if larger).
     - Writes standard bottom-up Windows row order with zeroed 4-byte row padding bytes (for 24-bpp) and zero ancillary metadata.
     - Zeroes `*out_data = NULL; *out_len = 0;` on entry and frees on any error.

3. **Verification and Gates (`tests/fixtures/write_tests.c`, `tests/test_parts.py` / `tests/test_ui.py`):**
   - C fixture `write-tests` (CONSOLE TIER 0, including `"png.h"` and `"bmp.h"` via public `ImpossibleParts` paths): tests all 5 PNG color types, `IM_PNG_WRITE_AUTO` selection, both `BGRA8` and `RGBA8` inputs, non-packed `stride > width * 4`, lossless refusal on invalid explicit modes, BMP 24-bpp & 32-bpp V4 encoding, overflow/BAD_ARG refusals, and full allocation-ordinal OOM sweep with 0 leaks.

     - Benchmarks 200 diverse deterministic pictures (UI icons, gradients, 2/4/16/256-color palettes, opaque/translucent grayscale, RGB, RGBA) comparing `IM_PNG_WRITE_AUTO` (`IM_DEFLATE_BALANCED`) against the reference PNG encoder, asserting `100 * sum(sdk_bytes) <= 103 * sum(ref_bytes)` and confirming palette (type 3) and gray (types 0/4) are chosen when lossless.
