# UI test machine implementation plan

**Goal:** live reference tests run in their own Hyper-V machine, take turns with inventory through Bosun, and never use the operator's desktop unasked.

**Architecture:** `tools/winvm/vm.ps1` builds the machine and runs one job in it. `tools/winvm/live.py` packs a whole test run (Python, the committed tree, the published reference program), takes its turn in Bosun and records the pass. The tests run inside the guest as they run on Windows today, so there is no remote protocol.

**Spec:** [docs/specs/2026-11-24-ui-test-vm-design.md](../specs/2026-11-24-ui-test-vm-design.md). **Method:** one session at a time, in the main session, because subagents here never write. Nontrivial diffs go through `scripts/review-dispatch.py` or `codex exec`.

## Global constraints

- 4 GB static memory, no network adapter, off between runs, nothing of the SDK in the checkpoint.
- The SDK's turn is at most 300 seconds. Inventory waits at most 360, then starts anyway.
- 5120 MB available to start, dropped 30 minutes after the first try. Retry every 2 minutes when nothing else is ready.
- Bosun's queue is `--ns Bosun.VM --slots 1`. Exit 75 means not now, everywhere.
- Machine name, folder and ISO come from `.conclave/local.toml`, never from code. No secret is printed.
- No em dash or en dash. Windows PowerShell 5.1 for `vm.ps1`.

## Review focus

- `vm.ps1` is killed mid-run: the guest shuts itself down at the 300 second limit, and the next run restores the checkpoint.
- Hyper-V refuses the start for memory: not now, with the reason, and the machine off.
- The job writes no exit code or times out: a failure, never a pass.
- The tree changes during a pass: the recorded fingerprint is the packed tree's, so the newer one is still owed.
- Bosun is not installed: the job runs directly, still behind the running-VM check.

### Task 1: the machine

**Files:** create `tools/winvm/vm.ps1`, `tools/winvm/common.ps1`, `tools/winvm/oobe-watch.ps1`; modify `.conclave/local.example.toml`.

**Produces:** `vm.ps1 -Build | -Run | -Stop -Name <n> -VmPath <dir>`; `-Build -IsoPath <iso> -ImageIndex <i>`; `-Run -In <dir> -Out <new dir> -Command <line> -HardSec <s> -Avoid <vm names>`. `-Out\result.json` is `{"outcome":"ran","exit":N,"seconds":S}` or `{"outcome":"not-now","reason":"..."}`. Process exit: the command's code, 75 not now, 3 unreachable, 2 bad argument.

**Produces:** `live.py` runs a pass (exit 0 passed or not owed, 1 failed, 75 not now); `--check` exits 0 when nothing is owed; `--wait` retries every 2 minutes. `fingerprint(root) -> str` is the SHA-256 of the tracked files under `reference/` and `tests/test_live.py`. A pass writes `docs/reviews/live-pass.json` `{fingerprint, commit, at, seconds}`; the first try of a fingerprint is in the ignored `build/live-try.json`. `IMPOSSIBLE_REFERENCE_EXE` replaces the build in `build_reference`. `Reference.exe` opens a window only with `IMPOSSIBLE_DISPLAY` set to `vm` or `desktop`.
